# Chatting Web App

A real-time chatting application built with React.js, Redux Toolkit, and Firebase. The application enables users to register, log in, and communicate through a modern chat interface.

## Features

* User Authentication
* User Registration & Login
* Real-Time Messaging
* Chat Interface
* Message Management
* Redux Toolkit State Management
* Responsive Design

## Tech Stack

* React.js
* Redux Toolkit
* Firebase Authentication
* Firebase Firestore
* JavaScript
* Vite

## Project Structure

* Authentication Module
* Chat Management
* User Interface Components
* Redux Store Integration
* Real-Time Data Handling

## Installation

git clone https://github.com/Kainaat-Fida/chatting-web-app.git

cd chatting-web-app

npm install

npm run dev
